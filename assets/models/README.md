# 3D-модели

Разместите здесь 3D-модели для проекта.

## Фруктовые блоки
Один универсальный префаб блока с rounded edges:
- `fruit_block.fbx` — Базовая модель блока (куб со скруглёнными углами)
  - Размер: 1x1x1 (масштабируется в скрипте до 0.3x0.3x0.3)
  - UV-развёртка для текстуры фрукта на лицевой стороне
  - Low-poly (~100-200 полигонов)

## Окружение
- `platform.fbx` — Круглая платформа для игрока
- `table.fbx` — Стол/постамент для башни блоков
- `collection_zone.fbx` — Корзина/контейнер зоны сбора

## Декоративные
- `cloud.fbx` — Декоративное облако (low-poly)
- `star.fbx` — Декоративная звезда (для эффектов)

## Рекомендации
- Формат: FBX или OBJ
- Полигональность: low-poly (до 500 на объект)
- Масштаб: 1 unit = 1 метр
- Центр объекта: в геометрическом центре модели
