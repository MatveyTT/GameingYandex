# Звуковые ассеты

Разместите здесь следующие аудиофайлы:

## Музыка
- `music_main.ogg` — Фоновая музыка (позитивная, лёгкая, зацикленная)
- `music_tension.ogg` — Напряжённая музыка (при приближении к проигрышу)

## Звуковые эффекты
- `hover.wav` — Наведение на блок (тихий «тинь», ~0.2с)
- `activate.wav` — Активация блока (хлопок / «поп», ~0.3с)
- `land.wav` — Приземление блока (мягкий удар, ~0.4с)
- `match.wav` — Совпадение пары (мелодичный «дзинь», ~0.5с)
- `chain.wav` — Цепная реакция (нарастающий «дзинь», ~0.6с)
- `fail.wav` — Проигрыш (грустный звук, ~1.0с)
- `win.wav` — Победа (фанфары, ~2.0с)
- `level_start.wav` — Начало уровня (весёлый джингл, ~1.5с)
- `button_click.wav` — Клик кнопки UI (~0.1с)
- `timer_warning.wav` — Предупреждение таймера (~0.3с)

## Рекомендации
- Формат: WAV для коротких эффектов, OGG для музыки
- Частота дискретизации: 44100 Hz
- Каналы: моно для 3D-звуков, стерео для музыки и UI
- Рекомендуемые источники: freesound.org, zapsplat.com (бесплатные)
