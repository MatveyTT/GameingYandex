# Текстуры

Разместите здесь текстуры для фруктовых блоков.

## Текстуры блоков
Для каждого фрукта нужна текстура лицевой стороны:

- `tex_apple.png` — Яблоко (красный фон, иконка яблока)
- `tex_orange.png` — Апельсин (оранжевый фон, иконка апельсина)
- `tex_banana.png` — Банан (жёлтый фон, иконка банана)
- `tex_grape.png` — Виноград (фиолетовый фон, иконка винограда)
- `tex_strawberry.png` — Клубника (розовый фон, иконка клубники)
- `tex_watermelon.png` — Арбуз (зелёный фон, иконка арбуза)

## UI-иконки
- `icon_apple.png` — Иконка яблока (64x64)
- `icon_orange.png` — Иконка апельсина (64x64)
- `icon_banana.png` — Иконка банана (64x64)
- `icon_grape.png` — Иконка винограда (64x64)
- `icon_strawberry.png` — Иконка клубники (64x64)
- `icon_watermelon.png` — Иконка арбуза (64x64)

## Прочие
- `tex_platform.png` — Текстура платформы
- `tex_table_wood.png` — Текстура стола
- `tex_collection_zone.png` — Текстура зоны сбора

## Рекомендации
- Размеры: 256x256 или 512x512 для блоков, 64x64 для иконок
- Формат: PNG с альфа-каналом
- Стиль: low-poly, яркие насыщенные цвета
