# Fruit Blocks VR (Varwin Hackathon 2026)

Прототип puzzle-игры для направления **VR Яндекс.Игры** на базе механики
референса «Фруктовые блоки: Занимательное удаление».

## Концепт

Игрок в виде от первого лица находится рядом с фруктовой башней и выполняет
**одно основное действие**: активирует блок (удар/клик контроллером).

После активации блок:
1. становится физическим (падает вниз),
2. попадает в нижнюю зону,
3. удаляется автоматически, если образовал пару с таким же фруктом рядом.

Цель: очистить поле.  
Ошибка: переполнить нижнюю зону или оставить непарные блоки без доступных ходов.

## Что уже реализовано в репозитории

- Ядро игровой логики на Python:
  - активация блока;
  - падение в нижнюю зону;
  - авто-удаление пары одинаковых блоков;
  - win/fail-state;
  - событие для VFX/SFX/подсказок.
- Набор пресетов уровней.
- Адаптер-контроллер для интеграции логики со сценой Varwin.
- Desktop-симуляция (быстрый локальный прогон без VR).
- Автотесты на ключевую механику.

## Быстрый запуск (Desktop)

```bash
python scripts/desktop_simulation.py
```

Команды в симуляции:
- `list` — список блоков,
- `pick <block_id>` — активировать блок,
- `auto` — активировать блок из подсказки,
- `state` — снимок состояния,
- `quit` — выход.

## Как подключить к Varwin

`src/fruit_blocks_vr/varwin_adapter.py` ожидает слой-обертку `VarwinBridge`.
Этот слой нужно реализовать в вашем Varwin-проекте (вызовы конкретных API сцены).
Быстрый старт для интеграции — файл `scripts/varwin_runtime_template.py`.

Минимальный контракт:
- `set_block_dynamic(object_id)`
- `play_sound(sound_id, target_object_id=None)`
- `spawn_vfx(effect_id, target_object_id=None)`
- `remove_object(object_id)`
- `set_highlight(object_id, enabled)`
- `show_message(text, duration_sec=3.0)`
- `finish_game(won, reason)`

Рекомендуемый сценарий в сцене:
1. Создать башню из фруктовых блоков (объекты сцены с уникальными ID).
2. Инициализировать `FruitBlocksGame` через `build_game(...)`.
3. Собрать `object_to_block` (ID объекта сцены -> ID блока логики).
4. Создать `VarwinGameController(game, bridge, object_to_block)`.
5. На событие удара/клика по объекту вызывать
   `controller.on_object_interacted(scene_object_id)`.

## Соответствие ключевым требованиям задания

- **FPV**: логика построена под взаимодействие от первого лица.
- **Одна механика действия**: только активация блока.
- **Физика и стратегия**: активация меняет расклад в нижней зоне, влияет на
  дальнейшие решения.
- **Понятность за 10 секунд**: короткий onboarding-текст + подсветка хода.
- **Fail-state**: переполнение нижней зоны / отсутствие доступных действий.
- **VFX/SFX**: событийная модель уже содержит триггеры `activate/match/win/fail`.
