## Описание игры

«Фруктовые Блоки VR» — это логическая VR puzzle-игра с физикой, в которой игрок стоит перед
трёхмерной конструкцией из фруктовых блоков и должен стратегически активировать их,
чтобы одинаковые блоки падали и сталкивались друг с другом, автоматически исчезая.

### Основная механика

1. **Игровое поле** — трёхмерная сетка (башня) из фруктовых блоков перед игроком
2. **Активация** — игрок наводит контроллер/руку на блок и нажимает кнопку (или касается)
3. **Падение** — активированный блок теряет опору и падает вниз под действием гравитации
4. **Совпадение** — два одинаковых фруктовых блока рядом автоматически исчезают с эффектами
5. **Стратегия** — порядок активации критически важен; ошибки блокируют пространство
6. **Проигрыш** — зона сбора переполнена, и больше нет возможных совпадений

## Управление

### Desktop-режим (FPV)
- **WASD** — перемещение
- **Мышь** — обзор
- **ЛКМ (левая кнопка мыши)** — активация блока
- **R** — перезапуск уровня
- **ESC** — пауза

### VR-режим
- **Контроллер** — наведение луча на блок
- **Триггер** — активация блока
- **Поворот головы** — обзор
- **Кнопка меню** — пауза

## Запуск

### Через Varwin XRMS
1. Откройте Varwin XRMS
2. Импортируйте проект (файл `.vwp`)
3. Запустите сцену `MainScene`
4. Выберите режим: Desktop или VR

### Настройка проекта в Varwin
Подробная инструкция по настройке сцены и объектов в Varwin XRMS
находится в файле `docs/varwin_setup_guide.md`.
