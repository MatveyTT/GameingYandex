## 1. Подготовка

### Системные требования
- Varwin XRMS 2024 или новее
- Windows 10/11 64-bit
- GPU с поддержкой DirectX 11
- Для VR: SteamVR-совместимая гарнитура

### Необходимые файлы
- Все файлы из папки `scripts/`
- Конфигурационные файлы из папки `config/`
- Ассеты из папки `assets/` (звуки, текстуры, модели)

---

## 2. Создание проекта

1. Откройте Varwin XRMS
2. Нажмите **«Создать новый проект»**
3. Название: `FruitBlocksVR`
4. Описание: `Фруктовые Блоки VR — логическая puzzle-игра`
5. Выберите шаблон: **«Пустой проект»**

---

## 3. Настройка сцены

### Создание главной сцены
1. В редакторе создайте новую сцену: **Сцена → Создать → MainScene**
2. Настройте освещение:
   - Directional Light: rotation (50, -30, 0), intensity 1.2
   - Ambient Light: цвет #B8D4E3, intensity 0.4
3. Настройте Skybox: мягкий градиент (голубой → белый)

### Иерархия объектов сцены

```
MainScene
├── GameController          (пустой объект, корневой скрипт)
├── Environment
│   ├── Platform            (круглая платформа под игроком)
│   ├── Table               (стол/постамент для башни блоков)
│   ├── CollectionZone      (зона сбора с прозрачными стенками)
│   │   ├── Floor           (пол зоны сбора)
│   │   ├── WallLeft        (левая стенка)
│   │   ├── WallRight       (правая стенка)
│   │   ├── WallFront       (передняя стенка, прозрачная)
│   │   └── WallBack        (задняя стенка)
│   └── Decorations
│       ├── Cloud_1-3       (декоративные облака)
│       └── Particles_Ambient (лёгкие частицы в воздухе)
├── BlocksContainer         (контейнер для фруктовых блоков)
│   └── [блоки создаются динамически]
├── UICanvas                (Canvas для UI-элементов)
│   ├── HUD
│   │   ├── ScoreText       (отображение очков)
│   │   ├── LevelText       (отображение уровня)
│   │   ├── TimerText       (таймер)
│   │   └── MovesText       (счётчик ходов)
│   ├── LevelStartPanel     (панель начала уровня)
│   ├── LevelCompletePanel  (панель завершения)
│   ├── GameOverPanel       (панель проигрыша)
│   ├── PausePanel          (панель паузы)
│   └── OnboardingPanel     (подсказки обучения)
├── AudioSources
│   ├── MusicSource         (фоновая музыка)
│   ├── SFXSource           (звуковые эффекты)
│   └── UISFXSource         (звуки UI)
├── VFXContainer            (контейнер для визуальных эффектов)
│   ├── MatchExplosionPrefab
│   ├── LandDustPrefab
│   ├── ActivationFlashPrefab
│   └── VictoryFireworksPrefab
└── PlayerSpawn             (точка спавна игрока)
```

## 4. Добавление объектов

### Платформа и стол
1. **Platform**: цилиндр, scale (3, 0.1, 3), position (0, -0.05, 0)
   - Материал: тёмно-серый с лёгкой текстурой дерева
2. **Table**: куб, scale (1.5, 0.8, 1.5), position (0, 0.4, 1.0)
   - Материал: светлое дерево

### Зона сбора (CollectionZone)
Позиция: (0, 0.8, 1.0), размер 2.0 x 2.0

1. **Floor**: куб, scale (2, 0.05, 2)
   - Collider: Box Collider, is_trigger = false
   - Материал: полупрозрачный, светло-голубой
2. **Стенки**: тонкие кубы по периметру
   - Collider: Box Collider
   - Материал: прозрачный с лёгкой рамкой

### Фруктовые блоки (Prefabs)
Создайте 6 префабов блоков:

Для каждого фрукта:
1. Куб с rounded edges (или Cube с Mesh Smooth)
2. Scale: (0.3, 0.3, 0.3)
3. Материал: цвет фрукта (см. `config/fruit_types.json`)
4. Текстура: иконка фрукта на лицевой стороне
5. Компоненты:
   - **Box Collider**: size (1, 1, 1)
   - **Rigidbody**: mass=1, drag=0.1, angular_drag=0.5
     - is_kinematic = true (по умолчанию)
     - use_gravity = false (по умолчанию)
   - **Physics Material**: bounce=0.2, friction=0.6
   - **Outline** (для подсветки при наведении)

### Точка спавна игрока
- **PlayerSpawn**: пустой объект, position (0, 0, -0.5)
- Игрок смотрит в направлении (0, 0, 1) — на башню блоков

## 5. Подключение скриптов

### Шаг 1: Импорт Python-файлов
1. В Varwin откройте раздел **Скрипты**
2. Импортируйте все файлы из папки `scripts/`

### Шаг 2: Привязка главного скрипта
1. Выберите объект **GameController**
2. Добавьте скрипт: `varwin_integration.py`
3. Класс: `FruitBlocksVR`
4. Метод `on_start()` привязан к событию **Start**
5. Метод `on_update()` привязан к событию **Update**

### Шаг 3: Привязка событий блоков
Для каждого префаба блока настройте события:
- **Pointer Enter** → `on_block_pointer_enter(block_id)`
- **Pointer Exit** → `on_block_pointer_exit(block_id)`
- **Pointer Click** → `on_block_click(block_id)`

### Шаг 4: Привязка UI-кнопок
- Кнопка «Следующий уровень» → `on_next_level_click()`
- Кнопка «Начать заново» → `on_restart_click()`
- Кнопка «Пауза» → `on_pause_click()`

## 6. Настройка физики

### Глобальные настройки
- **Physics.gravity**: (0, -19.62, 0) — удвоенная гравитация для быстрого падения
- **Default Contact Offset**: 0.01
- **Default Solver Iterations**: 6

### Физический материал блоков
- **Bounciness**: 0.2 (небольшой отскок)
- **Dynamic Friction**: 0.6
- **Static Friction**: 0.72
- **Bounce Combine**: Average
- **Friction Combine**: Average

### Слои столкновений
- Layer **Blocks**: все фруктовые блоки
- Layer **Walls**: стенки зоны сбора
- Layer **Floor**: пол зоны сбора
- Включите столкновения: Blocks↔Blocks, Blocks↔Walls, Blocks↔Floor

## 7. Настройка UI

### Canvas Settings
- **Render Mode**: World Space (для VR)
- **Позиция Canvas**: (0, 2.5, 2.0) — над башней блоков
- **Размер**: 2.0 x 1.0 метра
- **Scale**: (0.005, 0.005, 0.005)

### HUD
- **ScoreText**: верхний центр, белый, размер 32
- **LevelText**: верхний левый, белый, размер 24
- **TimerText**: верхний правый, белый, размер 28
- **MovesText**: под ScoreText, серый, размер 20

### Панели (скрыты по умолчанию)
Создайте панели с полупрозрачным фоном:
- Закруглённые углы
- Фон: чёрный 70-90% alpha
- Анимация появления: fade in + scale

## 8. Настройка звука

### Audio Sources
1. **MusicSource**: 2D, loop=true, volume=0.3, play_on_awake=false
2. **SFXSource**: 3D, spatial_blend=0.8, volume=0.7
3. **UISFXSource**: 2D, volume=0.5

### Необходимые аудиофайлы
Разместите в `assets/sounds/`:
- `music_main.ogg` — фоновая музыка
- `music_tension.ogg` — напряжённая музыка
- `hover.wav` — наведение на блок
- `activate.wav` — активация блока
- `land.wav` — приземление
- `match.wav` — совпадение
- `chain.wav` — цепная реакция
- `fail.wav` — проигрыш
- `win.wav` — победа
- `level_start.wav` — начало уровня
- `button_click.wav` — клик кнопки

## 9. Настройка VR

### Платформа VR
- Убедитесь, что SteamVR установлен и настроен
- В Varwin: **Настройки → VR → Включить VR-режим**

### Контроллеры
- Правый контроллер: луч наведения (Pointer)
- Триггер: активация/клик
- Кнопка меню: пауза

### Позиционирование
- Игрок стоит на **PlayerSpawn** (0, 0, -0.5)
- Башня блоков перед игроком на расстоянии ~1.5м
- Зона сбора на уровне пояса (~0.8м)

## 10. Экспорт

### Экспорт проекта
1. **Файл → Экспорт проекта целиком**
2. Формат: `.vwp`
3. Имя файла: `FruitBlocksVR.vwp`

### Тестирование
1. **Desktop**: запустите сцену в режиме Preview
2. **VR**: подключите гарнитуру и запустите в VR-режиме
3. Проверьте все механики:
   - Наведение и подсветка блоков
   - Активация и падение
   - Совпадения и исчезновение
   - Начисление очков
   - Фейл-стейт
   - Переходы между уровнями
   - Звуки и эффекты
