# Гейм-дизайн документ: Фруктовые Блоки VR

## 1. Концепция

### Высокоуровневое описание
«Фруктовые Блоки VR» — VR-адаптация казуальной puzzle-игры «Фруктовые блоки:
Занимательное удаление» из каталога Яндекс Игр. Игрок стоит перед трёхмерной
конструкцией из фруктовых блоков и должен стратегически выбирать и активировать
блоки так, чтобы одинаковые фрукты падали рядом друг с другом и исчезали.

### Целевая аудитория
- Казуальные игроки, знакомые с мобильными puzzle-играми
- Новички в VR, ищущие простой и понятный опыт
- Возраст: 10+

### Уникальное торговое предложение (USP)
Знакомая и простая puzzle-механика, переосмысленная для VR с физическим
присутствием и тактильным взаимодействием. «Поднять и играть» за 10 секунд.

## 2. Геймплей

### 2.1 Основной игровой цикл
1. Игрок видит башню из фруктовых блоков
2. Игрок наводит контроллер на блок и активирует его
3. Блок отсоединяется и падает вниз
4. Одинаковые блоки рядом автоматически исчезают
5. Очки начисляются за каждое совпадение
6. Уровень пройден, когда все блоки убраны
7. Проигрыш, если пространство заблокировано

### 2.2 Игровое поле
- Трёхмерная сетка блоков (от 3x3x3 до 5x5x5 в зависимости от уровня)
- Блоки расположены на «полках» / в ячейках конструкции
- Зона сбора внизу — платформа, куда падают блоки
- Зона сбора имеет ограниченную вместимость

### 2.3 Фруктовые блоки
Каждый блок представляет собой куб с текстурой фрукта:

| ID | Фрукт    | Цвет основы    | Частицы при уничтожении |
|----|----------|-----------------|------------------------|
| 0  | Яблоко   | Красный (#E74C3C)    | Красные искры     |
| 1  | Апельсин | Оранжевый (#E67E22)  | Оранжевые брызги  |
| 2  | Банан    | Жёлтый (#F1C40F)     | Жёлтые звёзды     |
| 3  | Виноград | Фиолетовый (#9B59B6) | Фиолетовые пузыри |
| 4  | Клубника | Розовый (#E91E63)    | Розовые сердечки   |
| 5  | Арбуз    | Зелёный (#27AE60)    | Зелёные капли      |

### 2.4 Механика совпадений
- Два одинаковых блока считаются «рядом», если расстояние между их центрами
  менее 1.5 размера блока
- При совпадении оба блока уничтожаются с визуальными и звуковыми эффектами
- Возможны цепные реакции: уничтожение блоков может привести к падению других
  блоков, которые создают новые совпадения
- Цепные совпадения дают бонусные очки

### 2.5 Фейл-стейт (условие проигрыша)
Игрок проигрывает, когда:
- Зона сбора заполнена (блоки достигли максимальной высоты)
- Оставшиеся блоки не могут быть сопоставлены (нет пар)
- Визуальный сигнал: экран краснеет, блоки в зоне сбора мигают
- Звуковой сигнал: звук «buzzer» / провала
- Кнопка «Начать заново» появляется перед игроком

## 3. Управление и взаимодействие

### 3.1 Основное действие
**Одно действие:** наведение + активация (клик/триггер)

### 3.2 Desktop
- Наведение мышью создаёт луч от камеры
- Блок подсвечивается при наведении (outline + увеличение на 5%)
- ЛКМ — активация блока

### 3.3 VR
- Контроллер направляет луч в пространство
- Блок подсвечивается при наведении луча
- Триггер контроллера — активация блока
- Хаптик-отклик при активации

### 3.4 Обратная связь
При наведении на блок:
- Контур подсветки (белый glow)
- Блок слегка увеличивается (scale 1.05)
- Тихий звук hover

При активации блока:
- Вспышка света на блоке
- Звук «щелчок» / «хлопок»
- Блок отсоединяется и начинает падать
- Хаптик-вибрация (VR)

При совпадении:
- Взрыв частиц цвета фрукта
- Звук «разрушения» / «pop»
- Текст «+очки» всплывает
- Экран слегка вспыхивает

## 4. Онбординг (обучение)

### Первые 10 секунд
1. **(0-3 сек)** Появляется текст: «Активируй фруктовые блоки!»
2. **(3-6 сек)** Один блок подсвечивается пульсирующим светом
3. **(6-10 сек)** Стрелка указывает на подсвеченный блок с текстом «Нажми»
4. После первой активации: текст «Одинаковые фрукты исчезают!»

### Визуальные подсказки
- Пульсирующая подсветка целевого блока
- Стрелки-указатели
- Иконка контроллера/мыши рядом с блоком

## 5. Прогрессия

### Уровни
| Уровень | Размер сетки | Типы фруктов | Сложность |
|---------|-------------|--------------|-----------|
| 1       | 3x3x2       | 3            | Обучение  |
| 2       | 3x3x3       | 3            | Лёгкий    |
| 3       | 4x3x3       | 4            | Средний   |
| 4       | 4x4x3       | 4            | Средний+  |
| 5       | 4x4x4       | 5            | Сложный   |
| 6       | 5x4x4       | 5            | Сложный+  |
| 7       | 5x5x4       | 6            | Эксперт   |
| 8       | 5x5x5       | 6            | Мастер    |

### Система очков
- Совпадение пары: 100 очков
- Цепное совпадение: 100 × множитель (x2, x3, x4...)
- Бонус за скорость: +50 очков если совпадение < 3 сек после предыдущего
- Бонус за полное прохождение: оставшееся время × 10

## 6. Визуальный стиль

### Общий стиль
- **Low-poly** с яркими, насыщенными цветами
- Чистый, минималистичный дизайн без визуального перегруза
- Мягкое освещение с лёгкими тенями
- Приятная пастельная палитра фона

### Окружение
- Игрок стоит на круглой платформе
- Перед игроком — стол/постамент с башней блоков
- Фон — мягкий градиент или абстрактное небо
- Лёгкие декоративные элементы (облака, частицы)

### Блоки
- Округлённые кубы (soft cubes) с текстурой фрукта
- Лёгкая анимация idle (покачивание)
- Яркие, контрастные цвета для каждого типа

## 7. Звуковой дизайн

### Фоновая музыка
- Лёгкая, позитивная мелодия
- Лупящийся трек, не утомляющий при повторе
- Темп увеличивается при приближении к фейл-стейту

| Действие              | Звук                    |

| Наведение на блок     | Тихий «тинь»           |
| Активация блока       | «Поп» / хлопок         |
| Падение блока         | Мягкий удар             |
| Совпадение            | Мелодичный «дзинь»     |
| Цепное совпадение     | Нарастающий «дзинь»    |
| Проигрыш              | Грустный «бу-бу»       |
| Победа                | Фанфары                |
| Начало уровня         | Весёлый джингл         |
| Кнопка UI             | Клик                   |
